# Changelog

## Version 3.1

- Added a connected five-way navigation controller with dedicated Menu, Back, and Input icons.
- Added high-contrast focus and configured-key indicators.
- Added a bundled TV builder library with native OK, direction, Menu, Back, and Input candidate groups.
- Added automatic first-launch library installation and a configurable library setting.
- Added native navigation editing, scanning, saving, exporting, and repeat support.
- Improved scan speed, signal caching, cancellation, file browsing, and project recovery.
